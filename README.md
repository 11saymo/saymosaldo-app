# MUNORA

MUNORA — личный финансовый помощник для учёта доходов и расходов, планирования бюджета и накоплений.

**Публичный сайт:** https://munora.ru/

## Возможности

- Учёт доходов и расходов.
- Категории операций и месячные лимиты.
- Финансовые цели и накопления.
- Регулярные платежи.
- Учёт долгов и обязательств.
- Локальный экспорт и восстановление резервной копии.
- Синхронизация данных между устройствами через личный аккаунт.
- Самостоятельное удаление аккаунта, облачных записей и резервных копий с повторным подтверждением входа.

## Архитектура

- **Клиент:** HTML, CSS и JavaScript без сторонних JavaScript-библиотек.
- **Хостинг:** GitHub Pages.
- **Авторизация:** Google OAuth через Supabase Auth с PKCE.
- **База данных:** Supabase Postgres.
- **Изоляция данных:** Row Level Security (RLS) — пользовательские записи доступны только владельцу аккаунта.
- **Офлайн-режим:** Service Worker и локальное хранилище браузера.

Клиентское приложение использует только публичный Supabase publishable key. Секретные ключи и ключи `service_role` не должны попадать в браузерный код или репозиторий.

## Важные замечания о данных

- Финансовые записи хранятся в облачном аккаунте и локальной копии браузера.
- Локальная копия и токены сессии не зашифрованы отдельным паролем MUNORA. Защищайте устройство блокировкой экрана и не используйте приложение на чужих устройствах.
- Не вводите PIN-коды, CVV, банковские пароли и другие секреты.
- MUNORA не подключается к банковским счетам и не запрашивает доступ к Gmail или Google Диску.
- Не публикуйте персональные и финансовые сведения в публичных GitHub Issues.

Подробности обработки данных: [Политика конфиденциальности](https://munora.ru/privacy.html).

## Проверки перед выпуском

Для локального запуска проверок нужны Node.js 22, Python 3 и Deno 2.

```bash
node --check app.js
node --check auth.js
node --check learning.js
node --test tests/*.test.cjs
python3 scripts/validate_release.py
node scripts/test_auth.js
node scripts/test_storage.js
node scripts/test_features.js
deno check supabase/functions/username-auth/index.ts
deno check supabase/functions/delete-account/index.ts
```

GitHub Actions автоматически запускает проверки качества и релиза. CodeQL выполняет статический анализ JavaScript, а Dependabot проверяет обновления GitHub Actions.

## Разработка

Изменения приложения публикуются через ветку `main`. Перед выпуском необходимо убедиться, что проверки GitHub Actions завершились успешно.
