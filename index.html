MUNORA — личный финансовый помощник

MUNORA — веб-приложение для личного учёта финансов. Оно помогает вести записи о доходах и расходах, планировать бюджет, контролировать регулярные платежи, лимиты, долги и цели накоплений.

Что можно делать в MUNORA

  • Записывать доходы и расходы и распределять их по категориям.
  • Следить за балансом и статистикой расходов.
  • Планировать месячный бюджет, лимиты и накопительные цели.
  • Учитывать регулярные платежи и задолженности.
  • Синхронизировать данные между устройствами и экспортировать резервную копию.

Вход и обработка данных

Для входа используется Google OAuth. MUNORA запрашивает только базовые данные профиля: идентификатор аккаунта, адрес электронной почты, имя и фотографию профиля, если они доступны. Приложение не запрашивает доступ к Gmail, Google Диску, контактам или календарю. Финансовые записи хранятся отдельно в аккаунте пользователя и не передаются Google.

Просматривать описание сервиса и юридические документы можно без входа. Вход требуется только для доступа к личным финансовым данным и функциям аккаунта.

MUNORA использует Google API только для аутентификации и базовой идентификации пользователя. Сервис не использует Google API для создания, запроса, хранения или распространения AI-generated non-consensual intimate imagery (AI NCII) и не предоставляет функций создания интимных изображений людей.
